# 🏠 Property Price Prediction

A Machine Learning web app that predicts property prices based on location, area, rooms & other features.

Built with **Python, Flask, Scikit-Learn** - B.Tech CSE Final Year Project | ABVGIET

---

## 🚀 Features

- Predict property price instantly
- User Authentication (Login / Signup)
- Interactive charts - Actual vs Predicted, Feature Importance, EDA
- Clean Flask UI with HTML / CSS / JS
- Model Comparison & Evaluation Metrics
- Unit Tests with Pytest

## 🛠️ Tech Stack

- **Language:** Python
- **Backend:** Flask
- **ML:** Scikit-Learn, Pandas, NumPy, Matplotlib
- **Frontend:** HTML, CSS, JavaScript
- **Testing:** Pytest

## ⚙️ How to Run

```bash
# 1. Clone repo
git clone https://github.com/Harshdeep037/property-price-prediction.git
cd property-price-prediction

# 2. Create venv
python -m venv .venv
.venv\Scripts\activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Train model
python train_model.py

# 5. Run app
python app.py
