About the project

The problem

Estimate a district's median house value from census-style data such as income, location and housing counts.

The method

Missing values are filled, ratio features are added, and numbers are scaled. Linear Regression (baseline) and Random Forest are compared with cross-validation, and the best one is saved.

Limitations

Data is from the 1990 census, rows are districts, and values above $500,000 are capped. Use it for learning, not for real appraisals.
